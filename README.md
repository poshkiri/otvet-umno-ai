# Пойми AI

Telegram-бот, который понимает фотографии и голос, отвечает на вопросы, помогает с текстами и создаёт изображения.

## Что уже работает

- 7 сценариев: разбор, ответ с нуля, проверка черновика, клиент, HR, покупатель, претензия;
- 5 контекстов переписки;
- вход текстом, скриншотом и голосовым сообщением;
- естественные вопросы голосом без выбора режима;
- автоматическое объяснение товаров, этикеток, документов, ошибок и задач по фото;
- продолжение диалога вопросами по последней фотографии;
- совместный анализ фотоальбомов и сравнение нескольких товаров;
- 8 быстрых улучшений ответа;
- история генераций и сохранённые шаблоны;
- бесплатный лимит, платные кредиты и продуктовая аналитика;
- генерация изображений: одна пробная картинка, месячные лимиты и восстановление попытки при ошибке;
- редактирование присланных фотографий: аниме-стиль, смена фона, добавление и удаление деталей текстом или голосом;
- ежемесячная подписка Plus через Telegram Stars: общий баланс 50 AI-единиц и до 20 картинок за 30 дней;
- SQLite без отдельного сервера базы данных.

## Telegram Mini App

В проект встроен полноэкранный сканер товаров и документов:

- открывается из главного меню и постоянной кнопки Telegram;
- использует камеру телефона или изображение из галереи;
- показывает подробный результат и поддерживает вопросы по фотографии;
- использует общие с ботом бесплатные запросы, Plus и купленные пакеты;
- проверяет подпись `Telegram.WebApp.initData` на сервере;
- не хранит фотографии после завершения запроса.

Локальный интерфейс в демонстрационном режиме:

```bash
npm run dev:webapp
```

В Telegram Mini App работает только по HTTPS. На Render адрес формируется автоматически из `RENDER_EXTERNAL_URL`; при другом хостинге укажи `MINI_APP_URL=https://example.com/app/`.

## Запуск

Требуется Node.js 22.22 или новее.

1. Создай бота через `@BotFather` и получи токен.
2. Создай `.env.local` на основе `.env.example`.
3. Заполни `BOT_TOKEN` и `OPENAI_API_KEY`.
4. Установи зависимости и запусти:

```bash
npm install
npm run dev
```

Для обычного запуска после сборки:

```bash
npm run build
npm start
```

## Администрирование

Укажи свой числовой Telegram ID в `ADMIN_TELEGRAM_ID`. После этого доступны:

- `/admin` или `/stats` — отчёт за сутки, 7/30 дней или всё время;
- `/grant TELEGRAM_ID КОЛИЧЕСТВО` — начислить купленные запросы.

Админский отчёт показывает активных и новых пользователей, типы запросов, созданные картинки, активные подписки, покупки, возвраты, конверсию, популярный пакет и текущий баланс Stars. После каждой оплаты владелец получает уведомление, а в `DAILY_REPORT_HOUR` — ежедневную сводку по часовому поясу `REPORT_TIMEZONE`.

Рекламный источник передаётся через start-параметр и навсегда закрепляется за первым запуском пользователя:

```text
https://t.me/USERNAME?start=instagram
https://t.me/USERNAME?start=tiktok_august
```

PostHog подключается опционально через `POSTHOG_API_KEY`. Пока ключ не указан, внутренняя аналитика и `/admin` продолжают работать. В PostHog отправляются только анонимный хеш пользователя, название события и технические параметры — без Telegram ID, имени, текста сообщений и фотографий. Для европейского проекта оставь `POSTHOG_HOST=https://eu.i.posthog.com`.

Оплата цифровых пакетов и подписки Plus проходит через Telegram Stars. Plus действует 30 дней и продлевается автоматически; пользователь может выключить и снова включить автопродление в боте. После события `successful_payment` бот атомарно записывает платёж. Пользователь видит историю в разделе «Мои покупки», а владелец может выполнить возврат командой `/refund ID_ПЛАТЕЖА`.

Для надёжности бот сверяет историю Stars после перезапуска, резервирует запрос до обращения к AI и возвращает резерв при технической ошибке. Updates обрабатываются параллельно через `@grammyjs/runner`, но последовательно для одного пользователя. Тяжёлые медиа ограничены по размеру и общей параллельности.

## Render

Проект содержит `render.yaml` для единого постоянного Web Service: он одновременно запускает бота, API и Mini App.

- тип сервиса: `Web Service`;
- тариф: `Starter`;
- регион: `Frankfurt`;
- диск: 1 ГБ, смонтирован в `/opt/render/project/src/data`;
- база: `/opt/render/project/src/data/bot.db`.

При создании Blueprint в Render вручную заполни секреты `BOT_TOKEN`, `OPENAI_API_KEY` и `ADMIN_TELEGRAM_ID`. Дополнительные ID команды указываются через запятую в `UNLIMITED_TELEGRAM_IDS`. Остальные настройки загрузятся из `render.yaml`.

После успешного запуска Render останови локальный экземпляр бота, иначе Telegram вернёт ошибку `409 Conflict` из-за двух процессов polling.

Если раньше бот работал как Background Worker, сначала создай новый Web Service из `render.yaml`, проверь `/health` и `/app/`, затем останови старый Worker. Два облачных экземпляра бота одновременно тоже вызовут `409 Conflict`.
