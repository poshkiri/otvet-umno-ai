# Пойми AI: чеклист перед запуском

Цель: проверить бота так, как его проверяет реальный пользователь, Platega и владелец проекта.

## 1. Быстрый контроль перед тестом

- [ ] Бот открывается по ссылке `https://t.me/OtvetUmnoAI_bot`.
- [ ] Команда `/start` показывает понятное первое сообщение.
- [ ] В меню нет лишних кнопок, основные действия видны сразу.
- [ ] Кнопка поддержки ведет на `@PoymiAI_support`.
- [ ] Документы доступны через `Аккаунт -> Документы` и команду `/documents`.
- [ ] Сервер отвечает: `https://poymi-ai.onrender.com/health`.

## 2. Основные AI-сценарии

- [ ] Текст: отправить обычный вопрос, например `Что такое инфляция простыми словами?`.
- [ ] Фото товара: отправить фото упаковки/косметики и спросить `что это и как использовать?`.
- [ ] Скриншот: отправить скрин ошибки и попросить объяснить, что делать.
- [ ] Учебная задача: отправить фото задачи или текстовый пример.
- [ ] Голос: отправить голосовой вопрос на 5-15 секунд.
- [ ] PDF: отправить небольшой PDF и спросить `что тут самое важное?`.
- [ ] Продолжение после фото: после ответа по фото задать уточняющий вопрос.

Ожидаемый результат: бот отвечает понятно, без технических названий моделей, без лишних звездочек Markdown, без зависания.

## 3. Картинки

- [ ] Создание: написать `Нарисуй минималистичный логотип для кофейни`.
- [ ] Изменение фото: отправить фото и попросить `добавь на стол деньги` или похожий простой запрос.
- [ ] Во время генерации бот показывает сообщение ожидания.
- [ ] После генерации есть понятная кнопка повторного действия.
- [ ] Если лимит закончился, бот показывает тарифы и не списывает попытку.

## 4. Оплата и тарифы

- [ ] Раздел `Тарифы` открывается из меню.
- [ ] Видны тарифы Plus на 1, 3, 6 и 12 месяцев.
- [ ] Видны разовые пакеты запросов.
- [ ] Пользователь понимает, что входит в Plus: AI-баллы, картинки, срок.
- [ ] После покупки Stars подписка или запросы начисляются автоматически.
- [ ] Раздел `Покупки` показывает историю.
- [ ] Если покупка не начислилась, пользователь видит, куда писать в поддержку.

## 5. Поддержка

- [ ] Команда `/paysupport` открывает поддержку без подписки.
- [ ] В тексте поддержки указан `@PoymiAI_support`.
- [ ] Пользователь понимает, что нужно прислать ID платежа и краткое описание проблемы.
- [ ] Кнопка поддержки кликабельная.

## 6. Админ-проверка

- [ ] Команда `/admin` доступна только владельцу.
- [ ] Статистика показывает пользователей, запросы, покупки и Stars.
- [ ] Поиск пользователя принимает чистый Telegram ID.
- [ ] Команда `/myid` показывает пользователю его ID.
- [ ] Админ может вручную выдать Plus.
- [ ] При ручной выдаче Plus в аккаунте пользователя показываются корректные AI-баллы и срок.
- [ ] История платежей и покупок помогает разобраться с обращением.

## 7. Проверка для Platega

- [ ] Политика конфиденциальности открывается: `https://poymi-ai.onrender.com/app/privacy`.
- [ ] Пользовательское соглашение открывается: `https://poymi-ai.onrender.com/app/terms`.
- [ ] Тарифы открываются: `https://poymi-ai.onrender.com/app/tariffs`.
- [ ] Поддержка открывается: `https://poymi-ai.onrender.com/app/support`.
- [ ] В документах нет названий AI-моделей.
- [ ] В документах есть правила оплаты, начисления, возвратов и поддержки.
- [ ] В документах указано, что 18+ контент не поддерживается.

## 8. Что фиксировать после теста

Для каждой проблемы записать:

- Дата и время.
- Что отправили пользователю или что нажали.
- Что ожидали.
- Что произошло.
- Скриншот ошибки.
- Telegram ID пользователя, если проблема связана с оплатой или лимитами.

## 9. Готовность к первому трафику

Бот можно показывать первым пользователям, когда:

- Все основные AI-сценарии работают.
- Оплата Stars проходит и начисляется.
- Поддержка видна и понятна.
- Админ может найти пользователя и вручную исправить начисление.
- Нет повторяющихся дублей в `/start`, аккаунте и тарифах.
- Есть понятный рекламный пост или короткий ролик с демонстрацией фото-разбора.
